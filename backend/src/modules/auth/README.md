# Module xác thực

Phạm vi Sprint 1:

- Tạo và tra cứu User/Role theo ERD.
- Đăng nhập cơ bản và xác minh thông tin đăng nhập.
- Lưu mật khẩu dưới dạng băm bằng thư viện phù hợp; không lưu mật khẩu thuần.
- Bảo vệ API và kiểm tra vai trò ở tầng backend.

Không tự tạo bảng hoặc trường ngoài ERD nếu chưa được nhóm thống nhất.
